How Storage & Sync Work

📱 100% On-Device Local Storage

All your transactions, savings goals, monthly budgets, and profile data are stored in your device's private local memory (Room SQLite on Android, localStorage in browser). No internet is required to record expenses, view charts, or get AI coaching!

🔐 Hardware Encrypted Cloud Vault

When online, data syncs using AES-256-GCM encryption. Cloud servers only receive encrypted cipher payloads. Even if cloud servers are breached, your financial details remain zero-knowledge unreadable.

⚡ Offline-to-Online Conflict Resolver

If you log expenses offline while traveling, SpendWise queues them locally as PENDING_PUSH. Upon reconnecting, the LWW (Last-Write-Wins) resolver merges records seamlessly without losing any offline deposits.
